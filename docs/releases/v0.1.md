把 B站 / YouTube / 任意直链的视频转成结构化笔记，落入本地 RAG 知识库，支持带时间戳引用的自然语言问答。数据全部留在本机，**纯 CPU 可运行**。

这是 videoRAG 的**首个 Windows 桌面版**。

## 下载与使用

下载 `videoRAG-0.1.0-windows-x64.zip`（约 382 MB），解压后**双击 `videorag.exe`**，直接出现应用窗口——无需安装 Python、Docker 或 ffmpeg。

| 文件 | 用途 |
|---|---|
| `videorag.exe` | 窗口形态（双击这个）：原生窗口，不会弹出命令行窗口 |
| `videorag-cli.exe` | 控制台形态：命令行排障、`--self-test` 自检、`--headless` 当本地服务用 |

## 系统要求

- Windows 10 1803+ / Windows 11
- 原生窗口依赖 **WebView2 Runtime**（Win11 与多数 Win10 已自带）与 **.NET 6+**（窗口后端桥接所需）。
  任一缺失时会自动回落到系统浏览器打开，功能不受影响

## 首次使用

1. 启动后默认监听 **8566** 端口（被占用会自动顺延），实际地址会写进日志
2. 打开「设置」页（快捷键 `Alt+5`），填入 LLM API Key。
   支持任意 OpenAI 兼容服务：DeepSeek（默认）、OpenAI、Ollama、vLLM、自建网关均可
3. 在「设置 → 本地模型」下载两个本地模型：
   - **SenseVoice**（约 240 MB）— 本地语音转写，纯 CPU
   - **bge-small-zh**（约 190 MB）— 本地向量化
   - 国内网络慢的话，可在同一页开启镜像加速（hf-mirror.com）

> 没有 LLM Key 也能用：下载、转写、检索全部正常，只有「生成笔记」和「问答」不可用。

## 本版功能

**知识库能力**

- **本地转写**：SenseVoice（sherpa-onnx int8，纯 CPU），带词/句级时间戳
- **结构化笔记**：摘要 / 章节（带时间戳）/ 要点 / 金句 / 术语表，可导出 Markdown
- **RAG 问答**：中文混合检索（向量 + ngram 全文），答案附**可点击的时间戳引用**，一键跳回原视频
- **视觉旁路**：几乎没有对白的视频（纯音乐 MV、PPT 录屏、教程演示）自动抽关键帧 + OCR，
  画面文字并入转写，笔记与检索同样可用
- **多轮追问会话**、关键词检索、历史记录
- **MCP 外挂**：以 Streamable HTTP 暴露，可被 Cline 等 agent 直接查询知识库

**桌面形态**

- 原生窗口（Edge WebView2），双击即用
- 本地转写**在进程内运行**——不需要额外容器或后台进程
- 数据目录：`%LOCALAPPDATA%\videoRAG`
- 便携模式：设环境变量 `VIDEORAG_PORTABLE=1`，数据落在 exe 同级 `./data`，整个目录可拷进 U 盘
- 日志：`%LOCALAPPDATA%\videoRAG\logs\videorag.log`
- 包内已含 ffmpeg（Windows 静态构建）

## 数据与迁移

数据目录结构与 Docker 版**完全一致**（`db/ lancedb/ notes/ models/ cookies/`），
可以在桌面版与 Docker 部署之间直接互相迁移。

> ⚠️ 不要让桌面版与 Docker **同时**打开同一个数据目录：SQLite / LanceDB 是单实例文件库，
> 双进程并发读写有损坏风险。

## Docker 部署

同一份代码也支持 Docker（适合 NAS / 家用服务器 / VPS）：

```bash
cp .env.example .env    # 填入 LLM_API_KEY
docker compose up -d    # → http://localhost:8566
```

## 已知限制

- 抖音 / 小红书需要登录 cookie（未充分测试）
- B站对数据中心 IP 有风控，导出浏览器 cookie 可显著提升成功率
- 本版**未做代码签名**，Windows SmartScreen 可能提示「未知发布者」，选择「仍要运行」即可
- 本版不带 faster-whisper 转写档（桌面端统一使用进程内 SenseVoice）；
  Docker 部署仍保留该档位

## 从源码构建

```bash
# 桌面包（Windows）
pwsh -File packaging/build-windows.ps1

# Docker
docker compose up -d --build
```
